# Movie Web App

A fast and responsive movie web application built with React and Vite. Discover new movies, search for your favorites, and view detailed information.

## Features

* **Search:** Find movies by title.
* **Movie Details:** View comprehensive details including synopsis, ratings, and release date.
* **Responsive Design:** Seamless experience across desktop and mobile devices.

## Tech Stack

* **Frontend:** React, JavaScript, HTML, CSS
* **Build Tool:** Vite
* **Version Control:** Git & GitHub
